# 期货指标策略回测引擎
## 编写策略代码

1. 导航栏中，依次点击"我的策略" - "指标策略" - "期货回测"

![236f1f3453a2557fac4a7a3de76c1d81.png](http://u.thsi.cn/imgsrc/pefile/236f1f3453a2557fac4a7a3de76c1d81.png)

2. 新建策略,点击进入策略编辑页面，如下图

![c619ca78c9dc55d5571b571c9fa4e95c.png](http://u.thsi.cn/imgsrc/pefile/c619ca78c9dc55d5571b571c9fa4e95c.png)

3. 右侧进行策略设置

![13eccf647b4d828fdc9607f1fb60aa96.png](http://u.thsi.cn/imgsrc/pefile/13eccf647b4d828fdc9607f1fb60aa96.png)

* 标的：回测合约，当选择标的为主连合约时，需要选择“主连回测方式”
* 回测区间：回测计算的起止时间
* 周期：指标计算基于的K线周期，支持日线、60分钟、30分钟、15分钟、5分钟或自定义
* 初始资金：回测开始时持有的资金
* 手续费
* 滑点：默认为1，表示成交价=撮合价格±当前标的最小变动价位\*1，撮合价格默认为当前周期收盘价
* 保证金比例
* 默认开仓数量：交易函数中不写入下单数量时，开仓以默认开仓数量下单，平仓以全部持仓下单
* 主连回测方式：【前/后复权】将主连合约价格进行前/后复权后再进行回测，确保价格连续；【主连链回测】采用回测区间内指定品种当时的主力合约来计算交易信号并进行交易，可选择主力合约换月后立即开仓或等待下一个信号

4. 下方编写策略代码，用户可点击“参考手册”，查询指标函数的相关说明

   ![ce22d20ea85529d95a1e77c39729e750.png](http://u.thsi.cn/imgsrc/pefile/ce22d20ea85529d95a1e77c39729e750.png)

* 策略源码：

```
MA5:=MA(C,P1);  //计算5日线
MA10:=MA(C,P2);     //计算10日线

MA5>MA10 AND BKVOL=0 AND SKVOL=0,BK;    //当5日线大于10日线且当前持仓为0时，买入开仓
MA5<MA10 AND BKVOL=0 AND SKVOL=0,SK;    //当5日线小于10日线且当前持仓为0时，卖出开仓

MA5<MA10 AND BKVOL>0,SP;    //当5日线小于10日线且当前持有多头仓位时，卖出平仓
MA5>MA10 AND SKVOL>0,BP;    //当5日线大于10日线且当前持有空头仓位时，买入平仓
```

## 策略回测

1. 完成策略设置和代码编写后，点击右上角“开始回测”，进行回测计算
2. 回测完成后，在“回测报告”页查看回测报告，包括收益分析、交易明细、历史持仓情况等
   ![f1b00574e931f466208342802b9aad23.png](http://u.thsi.cn/imgsrc/pefile/f1b00574e931f466208342802b9aad23.png)
3. 用户可点击“查看深度报告”，查看更加详细的回测报告
   ![317a0dfe5d501c641342ee2427a4bc5d.png](http://u.thsi.cn/imgsrc/pefile/317a0dfe5d501c641342ee2427a4bc5d.png)

## 参数优化

参数优化功能，用于调整策略内部可变参数，以寻找策略表现最佳的参数值。以双均线策略为例，使用参数优化功能来寻找两条均线的最优周期数：

1. 设置参数名称、最小值、最大值、步长、默认值等，回测工具会在参数的最大最小值之间，以设定步长遍历待选值，并代入策略执行回测

![556065763cc4777a8b130c1444e46e65.png](http://u.thsi.cn/imgsrc/pefile/556065763cc4777a8b130c1444e46e65.png)

2. 设置参数之间的约束关系，如P1<P2。合理设定参数约束关系，可以减少参数搜索空间，提高寻参效率

![d4d53d41b2f32107136c8311ebe89164.png](http://u.thsi.cn/imgsrc/pefile/d4d53d41b2f32107136c8311ebe89164.png)

3. 完成参数设置之后，执行“参数优化”功能，计算完成后会显示参数优化结果
   ![d17c3427fac757b3ef6125a26683a924.png](http://u.thsi.cn/imgsrc/pefile/d17c3427fac757b3ef6125a26683a924.png)
