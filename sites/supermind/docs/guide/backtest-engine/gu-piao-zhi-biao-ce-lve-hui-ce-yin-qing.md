# 股票指标策略回测引擎
## 编写策略代码

1. 导航栏中，依次点击"我的策略" - "指标策略" - "股票回测"

![4346677e1bbb1a04f60387347ce40629.png](http://u.thsi.cn/imgsrc/pefile/4346677e1bbb1a04f60387347ce40629.png)

2. 新建策略,点击进入策略编辑页面，如下图

![9fb25649085662e6ebc048b72e0b06d2.png](http://u.thsi.cn/imgsrc/pefile/9fb25649085662e6ebc048b72e0b06d2.png)

3. 右侧进行策略设置

![145de69e9bac7bd34e5dec914b096a2e.png](http://u.thsi.cn/imgsrc/pefile/145de69e9bac7bd34e5dec914b096a2e.png)

* 标的：回测的股票
* 回测区间：回测计算的起止时间
* 复权方式：支持前复权、后复权、不复权
* 周期：指标计算基于的K线周期，支持日线、60分钟、30分钟、15分钟、5分钟或自定义
* 初始资金：回测开始时持有的资金
* 手续费
* 涨跌停成交限制：启用之后在触及涨跌停时不会撮合成交
* 滑点：单位为0.01元，默认为1，表示成交价=下一周期开盘价±1\*0.01
* 初始持仓：回测开始时持有的股票数量

4. 下方编写策略代码，用户可点击“参考手册”，查询指标函数的相关说明

   ![0036d50aa6ab906c367ce796183d86a9.png](http://u.thsi.cn/imgsrc/pefile/0036d50aa6ab906c367ce796183d86a9.png)

* 策略源码：

```
/*
以下为双均线策略
当短周期均线上穿长周期均线时, 买入当前现金的80%;
当短周期均线下穿长周期均线时, 卖出所有
*/
N:=ROUND(CASH*0.8/CLOSE/100,0)*100; //计算交易数量

MA1:MA(CLOSE,10); //计算短周期均线，并在图中绘制
MA2:MA(CLOSE,240); //计算长周期均线，并在图中绘制

BUYSIG:=CROSS(MA1,MA2); //短周期均线上穿长周期均线时, 出买入信号
SELLSIG:=CROSS(MA2,MA1); //短周期均线下穿长周期均线时, 出卖出信号

BUY(BUYSIG AND HOLDING=0,N);//当出现买入信号, 且持仓为0时, 执行买入
SELL(SELLSIG AND AVHOLDING>0,AVHOLDING);//当出现卖出信号, 且持仓不为0时, 执行卖出
```

## 策略回测

1. 完成策略设置和代码编写后，点击右上角“开始回测”，进行回测计算
2. 回测完成后，在“回测报告”页查看回测报告，包括收益分析、交易明细、历史持仓情况等

   ![5d964a5cd00ec203b2491edc3af498df.png](http://u.thsi.cn/imgsrc/pefile/5d964a5cd00ec203b2491edc3af498df.png)

## 参数优化

参数优化功能，用于调整策略内部可变参数，以寻找策略表现最佳的参数值。以双均线策略为例，使用参数优化功能来寻找两条均线的最优周期数：

1. 设置参数名称、最小值、最大值、步长、默认值等，回测工具会在参数的最大最小值之间，以设定步长遍历待选值，并代入策略执行回测

   ![44998fa3897e22972f565540454e18ee.png](http://u.thsi.cn/imgsrc/pefile/44998fa3897e22972f565540454e18ee.png)
2. 设置参数之间的约束关系，如P1<P2。合理设定参数约束关系，可以减少参数搜索空间，提高寻参效率

   ![f575084881cab3bb9b47c64b79f67b9d.png](http://u.thsi.cn/imgsrc/pefile/f575084881cab3bb9b47c64b79f67b9d.png)
3. 完成参数设置之后，执行“参数优化”功能，计算完成后会显示参数优化结果
   ![d17c3427fac757b3ef6125a26683a924.png](http://u.thsi.cn/imgsrc/pefile/d17c3427fac757b3ef6125a26683a924.png)
