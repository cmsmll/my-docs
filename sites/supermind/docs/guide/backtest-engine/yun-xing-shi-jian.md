# 运行时间
---

1.开盘前(9:00)运行：
　　before_trading函数
2.盘中运行：
　　handle_bar函数
　　　>日回测9:31:00运行一次，配置enable_open_bar后于9:30:00运行
　　　>分钟回测9:31:00-11:30,13:01:00-15:00:00，每分钟运行一次，配置enable_open_bar后于9:30:00增加一次运行
　　　>tick回测9:30:03-11:30,13:00:03-15:00:00，每3秒钟运行一次
3.收盘后(15:30)运行：
　　after_trading函数
